# 영업일지 앱 시범 운영 안내

## 1. 시범 사용자 설치 (약 5분)

1. 받은 `wj_code.zip` 을 한글이 없는 폴더(예: `C:\wj_code`)에 압축 풀기
2. PowerShell 을 열어 아래 두 줄 실행 (서버 주소는 관리자가 알려 준 한 줄)

```
cd C:\wj_code\wj
powershell -ExecutionPolicy Bypass -File .\desktop_app\install_wj.ps1 -ApiUrl "서버주소"
```

3. 바탕화면의 `영업일지` 아이콘을 더블클릭 → 평소 계정으로 로그인
4. 창 제목에 `v0.4.0` 처럼 버전이 보입니다.

- 파이썬이 없다는 메시지가 나오면 https://www.python.org/downloads/ 에서 설치하며 "Add python.exe to PATH" 를 체크한 뒤 다시 실행
- 지우고 싶을 때: `powershell -ExecutionPolicy Bypass -File .\desktop_app\install_wj.ps1 -Uninstall` (데이터는 구글 시트에 그대로 있습니다)
- 이전 방식(웹)으로는 언제든 계속 쓸 수 있습니다.

## 2. 쓰는 방법 (달라진 점)

- 한 번 열었던 화면은 다시 열 때 거의 바로 열립니다. 첫 로그인과 오늘 처음 여는 화면은 평소처럼 몇 초 걸립니다.
- 다른 사람이 방금 쓴 내용이 안 보이면 화면 오른쪽 아래 **↻ 최신 데이터 받기** 를 누르세요.
- 글을 저장하면 구글 시트에 기록됩니다. 번역본은 저장 후 몇 초 뒤에 나타납니다.
- 사진은 작은 것만 올라갑니다 (한 장 약 46,000자 이내).
- **공용 PC 에서는 "이 PC 에서 자동 로그인"을 켜지 마세요.**

## 3. 문제가 생기면

1. 무엇을 하다가, 몇 시쯤, 어떤 화면/메시지였는지 메모
2. PowerShell 에서 아래 실행 → 바탕화면에 `wj_점검_날짜.txt` 가 생김 (비밀번호·로그인 열쇠는 들어가지 않음)

```
& "$env:LOCALAPPDATA\WJApp\venv\Scripts\python.exe" "$env:LOCALAPPDATA\WJApp\app\wj_app.py" --diag
```

3. 메모와 점검 파일을 관리자에게 보내기

## 4. 관리자 점검표 (시범 기간 매일 5분)

| 항목 | 방법 | 합격 기준 |
|---|---|---|
| 데이터 백업 | `python pc_server\backup_journal.py` (시범 시작 전 + 매일) | 오류 없이 끝남 |
| 시트 확인 | 구글 시트 JOURNAL 탭에서 시범 사용자가 쓴 칸 확인 | 내용·작성자 정확, 중복·유실 없음 |
| 속도 | 시범 사용자의 점검 파일 '동작별 시간' | 화면:저장본 평균 0.1초 이하 |
| 서버 지연 | 점검 파일의 `서버:save`, `서버:login` 시간 | 저장 5초 이내 (시범 첫날 기준값 기록) |
| 오류 | 점검 파일의 '최근 실패·오류' | 반복되는 오류 없음 |
| 번역 | 저장 후 번역본이 나타나는 시간을 시계로 기록 | 첫날 기준값 기록 후 비교 |

### 시범 시작 전 (관리자 1회)
- [ ] 구글 데이터를 PC 에 백업 (`backup_journal.py`)
- [ ] 내 PC 에서 지워도 되는 칸에 "테스트" 저장 → 구글 시트 반영, 번역, 충돌 확인 후 칸 비우기
- [ ] 새 아이콘이 열리고 로그인되는지 확인

### 시범 종료 판단
- 설치: 시범 사용자 전원 한 번에 성공
- 저장: 유실·충돌 오류 0건
- 속도: 화면 이동이 체감상 즉시
- 안정성: 1주 동안 멈춤·로그인 풀림 반복 없음
